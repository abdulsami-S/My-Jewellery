# 💎 My Jewellery — Jewellery Showcase Web App

A full stack web application designed to showcase jewellery products with a clean, elegant, and responsive interface. This project demonstrates frontend design, backend integration, and dynamic product handling.

---

## 🚀 Features
- Responsive UI for desktop and mobile
- Product listing and display system
- Interactive navigation
- Dynamic content rendering using backend logic
- Organized product structure for easy browsing

---

## 🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript  
Backend: Python  

---

## 📂 Project Structure
```
project/
 ├── static/
 ├── templates/
 ├── app.py
 └── requirements.txt
```

---

## ⚙️ Installation & Setup

Clone repository
```
git clone https://github.com/abdulsami-S/My-Jewellery.git
cd My-Jewellery
```

Install dependencies
```
pip install -r requirements.txt
```

Run project
```
python app.py
```

Open in browser
```
http://localhost:5000
```

---

## 🎯 Purpose
This project was built to practice full stack web development concepts including UI design, backend logic, and integration between frontend and server-side components.
